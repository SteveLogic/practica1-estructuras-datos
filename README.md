# Practica 1 - Estructuras de Datos

Sistema de gestion de tickets desarrollado en Java para el curso SOFT-10 Estructuras de Datos.

## Funcionalidades

### Usuario
- Crear tickets.
- Consultar tickets resueltos mediante su ID.

### Administrador
- Visualizar el ticket al frente de la cola.
- Resolver el ticket al frente.

## Estructuras utilizadas

- Cola de prioridad para almacenar tickets pendientes.
- Lista enlazada simple para almacenar tickets resueltos.
